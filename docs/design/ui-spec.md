# UI 规格（UI Spec）

> 占位文件，将在 Iteration 1 后期补充。
> 计划交付：Dashboard 和 Blueprint 编辑器两屏的字段、事件、状态。

## 计划页面

- [ ] Dashboard（`/`）
- [ ] Blueprint 列表（`/blueprints`）
- [ ] Blueprint 编辑器（`/blueprints/new` 和 `:id/edit`）
- [ ] Run 详情（`/runs/:id`）

设计原则：

- 暗色主题默认
- 高信息密度，但不杂乱
- 实时反馈优先
- 错误状态优先级最高
