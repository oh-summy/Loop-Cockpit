# Architecture Decision Records (ADR)

> 每一个**会影响未来 3 个月以上**的技术决定，必须写一份 ADR。
> 文件名规范：`NNNN-kebab-case-topic.md`。

## ADR 模板

```markdown
# ADR-NNNN: Title

- **Status**: Proposed / Accepted / Deprecated / Superseded by ADR-XXXX
- **Date**: YYYY-MM-DD
- **Owner**: @username

## Context
[为什么会有这个决定？背景是什么？]

## Decision
[决定了什么？一句话能说清的那种。]

## Consequences
- ✅ 好处 1
- ✅ 好处 2
- ⚠️ 代价 1
- ⚠️ 代价 2

## Alternatives Considered
- 方案 A：拒绝原因
- 方案 B：拒绝原因
```
