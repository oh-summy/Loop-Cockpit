# 2026-06-24 · Kickoff

今天给 Loop Cockpit 这个项目正式立项。

## 为什么做这个

行业范式正在从 Prompt Engineering 转向 Loop Engineering，但市面上没有一个**给独立开发者用的、本地的、可视化的 Loop 设计器**。
OpenHermit 太重（PostgreSQL + Docker），LangChain 是 SDK 不是产品，Cron + Shell 又太原始。
我想做的就是那个空白：一个 `npx loop-cockpit start` 就能用、能在浏览器里画 Loop、能让 Claude Code / OpenCode / Kimi Code 在沙箱里自主迭代的工具。

## 学到的

- LLM 一把梭写出来的文档**看着完整其实没经过我脑子**，必须自己再过一遍——尤其是 Non-Goals 这种"绝不做"的条目
- Trigger 系统从第一天就要按事件总线设计，否则后期加邮件/PR/飞书每加一个都要改核心
- 独立开发者的最大敌人不是难度，是 scope creep——所以 Non-Goals 比 PRD 更重要
- CLAUDE.md 和"运行时契约"是两个东西，混在一份文档里会让 AI 精分
